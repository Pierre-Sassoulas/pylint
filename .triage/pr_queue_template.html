Three ways CI is absent

Half this queue has no test result, for three different reasons, and only one of them is the contributor's fault.

  • Held for approval — a run exists in action_required and a maintainer has to release it. One click, and the whole matrix reports.
  • Never ran — the queued run expired before anyone approved it. No click will help; the head has to move, or the PR has to be closed and reopened.
  • Red — the matrix ran and failed. This is the only one that is genuinely the author's move.

A pull request reading never ran is invisible to everyone: no red cross to chase, no green tick to merge. Across the whole table {n_silent} pull requests carry no comment at all — not a bot's, not a maintainer's.

A second, quieter tax: {n_conflict} of {total} conflict with main. Several are waiting on a review that could not be acted on anyway until they rebase — worth saying so before reading them.
