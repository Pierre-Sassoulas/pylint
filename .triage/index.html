How to read a verdict

  • Every verdict below was re-run after d03727c85 (Upgrade astroid to 4.3.1) landed; none of them moved.
    • reproduces — the reporter's own snippet was rebuilt and still emits the reported message on pylint main, with their library installed at a version that shows it.
    • fixed — no longer reproduces, and the commit that fixed it is named and hand-checked against its parent.
    • never repro'd — clean at the exact pylint, astroid and Python in the report, so nothing was fixed; something in the reporter's environment was doing the work.
    • needs repro / not re-run — the issue points at code that was never public, or carries no runnable case at all. Not a judgement on whether the bug is real.
